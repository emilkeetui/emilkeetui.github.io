# Assets folder

Drop the following files here. They are referenced by the site but are **not yet
present** — until you add them, their links/images will 404 on the live site.

| File | Referenced by | Purpose |
|------|---------------|---------|
| `profile.jpg` | `index.qmd` (about photo) | Your headshot on the home page. Square image works best (e.g. 400×400). |
| `cv.pdf` | `_quarto.yml` navbar → CV | Your curriculum vitae. |
| `jmp.pdf` | `research.qmd` → Job Market Paper | Your job market paper PDF. |
| `other_paper.pdf` | `research.qmd` (commented-out template) | Only needed if you un-comment the Working Papers section. |

Keep the file names exactly as above, or update the references in the `.qmd`
files / `_quarto.yml` to match your names.

You can delete this README once the real files are in place.
